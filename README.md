# GREEN-API Chat (Тестовое задание)

Пользовательский интерфейс для отправки и получения текстовых сообщений в мессенджере MAX через сервис [GREEN-API](https://green-api.com/).

Интерфейс стилизован под веб-версию мессенджера MAX (включая фирменный паттерн фона, цвета и иконки).

## Стек технологий
*   **React 18** (Vite)
*   **TypeScript**
*   **SCSS Modules** (для изолированной стилизации)
*   **Axios** (для работы с API)
*   **clsx** (для условных классов)
*   **Feature-Sliced Design (упрощенный)** — разделение на `containers` (логика) и `components` (презентация).

## Локальный запуск

Для запуска проекта вам потребуется установленный [Node.js](https://nodejs.org/) (версия 18 или выше).

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/syndicate13/green-api-chat.git
    cd green-api-chat

2. Установите зависимости:
   ```bash
   npm install
   
3. Запустите проект в режиме разработки:
   ```bash
   npm run dev 
4. Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).

## Как пользоваться

1. Авторизация: На экране входа введите ваш idInstance и apiTokenInstance от инстанса GREEN-API (MAX).

2. Примечание: Для работы входящих сообщений в настройках вашего инстанса на сайте GREEN-API должен быть включен параметр incomingWebhook, а поле webhookUrl — пустым. (Приложение использует метод receiveNotification — Long Polling).

3. Создание чата: Введите номер телефона получателя в формате 79991234567. Приложение проверит наличие аккаунта в MAX через метод checkAccount и создаст чат.

4. Общение: Отправляйте сообщения (Enter — отправить, Shift+Enter — перенос строки). Ответы будут подгружаться автоматически.

## Реализованные требования ТЗ

1. Интерфейс для отправки и получения сообщений.
2. Работа с сервисом GREEN-API.
3. Отправка и получение только текстовых сообщений.
4. Отправка через метод SendMessage.
5. Получение через метод receiveNotification (с обязательным DeleteNotification).
6. Внешний вид, максимально приближенный к прототипу web.max.ru.
7. Простой и понятный интерфейс с минимальным набором функций.
8. Технология React.
